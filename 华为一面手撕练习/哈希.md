01 / 217 · 存在重复元素
HashSet

要解决什么　判断是否有任意数字至少出现两次。
💡 一句话记住

集合只记录出现过没有；不需要次数。

① 怎么做
1. 遍历每个数字，加入集合。
2. 如果 add 返回 false，说明已存在，返回 true。
3. 遍历结束返回 false。
② 跟一遍例子
[1,2,3,1] → 第二次加入 1 失败 → true
③ 最容易错的地方
- Set.add(x) 首次加入返回 true，重复加入返回 false。
- 最坏情况下没有重复，需要存入全部数字。
时间	额外空间
平均 O(n)	O(n)

02 / 1 · 两数之和
数字 → 下标

要解决什么　找两个不同下标，使两个数的和等于 target。
💡 一句话记住

枚举当前数，在之前出现的数字中查找补数。

① 怎么做
1. 计算 need = target-nums[i]。
2. Map 中存在 need：返回它的下标与 i。
3. 否则把 nums[i] → i 加入 Map。
② 跟一遍例子
nums=[2,7,11,15]，target=9
读 2：查 7，未找到，存 2→0
读 7：查 2，找到，返回 [0,1]
③ 最容易错的地方
- 必须先查询、后插入，避免与自身配对。
- [3,3] 可以配对，两个下标不同即可。
- 返回下标，不是数字。
时间	额外空间
平均 O(n)	O(n)

03 / 49 · 字母异位词分组
特征 → 单词列表

要解决什么　把字母种类和各字母次数相同的单词分为一组。
💡 一句话记住

为同一组单词构造完全相同的键。

① 怎么做
1. 基础法：将字符排序，用排序结果作 key。
2. 把原单词加入 key 对应的列表。
3. 进阶法：统计 26 个字母频次，用带分隔符的计数字符串作 key。
② 跟一遍例子
eat、tea、ate → 排序键 aet → 同一组
tan、nat      → 排序键 ant → 同一组
③ 最容易错的地方
- Java int[] 默认按对象身份比较，不能直接作为内容键。
- 频次之间加分隔符，避免 [1,11] 与 [11,1] 混淆。
- 结果顺序不限，无需额外排序每个分组。
时间	额外空间
排序 O(nL log L)；计数 O(n(L+26))	O(n(L+26))，宽松上界

04 / 128 · 最长连续序列
HashSet + 起点判断

要解决什么　找数值连续的最长序列长度，不要求下标连续。
💡 一句话记住

只有不存在 x-1 的数，才是连续段的起点。

① 怎么做
1. 先把数字放入集合去重。
2. 若存在 x-1，直接跳过 x。
3. 否则向后查 x+1、x+2……，统计段长并更新答案。
② 跟一遍例子
[100,4,200,1,3,2]
只从 1、100、200 扩展
1 → 2 → 3 → 4，最长长度 4
③ 最容易错的地方
- 外层遍历去重后的集合，避免重复起点反复扩展。
- 从每个数都扩展会退化为 O(n²)。
- Java 整数边界需避免 x-1、current+1 溢出。
时间	额外空间
平均 O(n)	O(n)

05 / 560 · 和为 K 的子数组
前缀和 → 次数

要解决什么　统计和为 k 的连续、非空子数组个数。
💡 一句话记住

当前前缀和为 sum，只需统计之前 sum-k 出现了几次。

① 怎么做
1. 初始化 count[0]=1，代表空前缀。
2. 读入当前数，更新 sum。
3. 答案加上 count[sum-k]。
4. 再将 count[sum] 加 1。
② 跟一遍例子
[1,1,1]，k=2
sum=1：查 -1，新增 0 个
sum=2：查  0，新增 1 个
sum=3：查  1，新增 1 个
答案 = 2
③ 最容易错的地方
- 先查询再更新次数，避免统计空子数组。
- 存次数而非存在性：[0,0]、k=0 有 3 个答案。
- 有负数时不具备窗口和单调性，不能直接套普通滑动窗口。
时间	额外空间
平均 O(n)	O(n)

公式卡片

prefix[r] - prefix[l] = k

所以查询 prefix[l] = prefix[r] - k，其中 l < r。

import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            if (!seen.add(x)) return true;
        }
        return false;
    }
}

import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> index = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int need = target - nums[i];
            if (index.containsKey(need)) {
                return new int[]{index.get(need), i};
            }
            index.put(nums[i], i);
        }
        return new int[0]; // 题目保证有解，正常不会执行
    }
}

import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();
        for (String word : strs) {
            char[] chars = word.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);
            groups.computeIfAbsent(key, t -> new ArrayList<>()).add(word);
        }
        return new ArrayList<>(groups.values());
    }
}
进阶写法 · 26 字母频次键
import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> groups = new HashMap<>();
        for (String word : strs) {
            int[] counts = new int[26];
            for (char c : word.toCharArray()) counts[c - 'a']++;

            StringBuilder keyBuilder = new StringBuilder();
            for (int count : counts) {
                keyBuilder.append('#').append(count);
            }
            String key = keyBuilder.toString();
            groups.computeIfAbsent(key, t -> new ArrayList<>()).add(word);
        }
        return new ArrayList<>(groups.values());
    }
}

128 · 最长连续序列
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) set.add(x);

        int best = 0;
        for (int x : set) { // 遍历去重后的集合
            if (x != Integer.MIN_VALUE && set.contains(x - 1)) continue;

            int current = x;
            int length = 1;
            while (current != Integer.MAX_VALUE && set.contains(current + 1)) {
                current++;
                length++;
            }
            best = Math.max(best, length);
        }
        return best;
    }
}

560 · 和为 K 的子数组
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int subarraySum(int[] nums, int k) {
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1);
        int sum = 0;
        int answer = 0;

        for (int x : nums) {
            sum += x;
            answer += count.getOrDefault(sum - k, 0);
            count.put(sum, count.getOrDefault(sum, 0) + 1);
        }
        return answer;
    }
}
