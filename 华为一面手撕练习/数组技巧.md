01 / 189 · 轮转数组
三次翻转

要解决什么　把数组向右轮转 k 位，原地修改。
💡 一句话记住

先交换两段的位置，再恢复各段内部顺序。

① 怎么做
1. 先执行 k %= n，去掉完整轮转。
2. 翻转整个数组 [0,n-1]。
3. 翻转前 k 个元素 [0,k-1]。
4. 翻转剩余元素 [k,n-1]。
② 跟一遍例子
[1,2,3,4,5,6,7]，k=3
整体翻转 → [7,6,5,4,3,2,1]
前段翻转 → [5,6,7,4,3,2,1]
后段翻转 → [5,6,7,1,2,3,4]
③ 最容易错的地方
- 空数组先返回，再取余。
- 原数组分成前 n-k 个、后 k 个；结果是后段在前。
- k=0 时直接结束；翻转函数使用 left < right。
时间	额外空间
O(n)	O(1)

02 / 56 · 合并区间
排序后扫描

要解决什么　合并全部重叠的闭区间。
💡 一句话记住

当前区间只需与结果中最后一个已合并区间比较。

① 怎么做
1. 按左端点升序排序。
2. 结果为空，或 last.end < current.start：加入新区间。
3. 否则有重叠：last.end = max(last.end,current.end)。
② 跟一遍例子
[1,3] + [2,6] → [1,6]
[1,6] 与 [8,10] 断开 → 保留两段
③ 最容易错的地方
- 端点相等也要合并：[1,4] 与 [4,5] → [1,5]。
- 比较合并后的末段；不能只比较原数组的相邻两项。
- 右端点取最大值，避免包含关系使区间缩短。
时间	额外空间
O(n log n)	O(n)

03 / 41 · 缺失的第一个正数
原地哈希

要解决什么　找出未出现的最小正整数，要求线性时间、常数额外空间。
💡 一句话记住

把数字 x 放到下标 x-1，原数组就是存在性记录。

① 怎么做
1. 只处理 1 ≤ x ≤ n 的数字。
2. 目标位置还不是 x 时，交换到下标 x-1；用 while 继续处理换来的数。
3. 扫描首个 nums[i] != i+1，返回 i+1。
4. 全部归位则返回 n+1。
② 跟一遍例子
[3,4,-1,1]
→ [-1,4,3,1]
→ [-1,1,3,4]
→ [1,-1,3,4]
下标 1 应为 2 → 答案 2
③ 最容易错的地方
- 答案范围是 [1,n+1]，需要归位的数字范围是 [1,n]。
- 重复值必须停止：nums[nums[i]-1] != nums[i]。
- 先判断范围，再访问目标位置；交换前保存 target。
时间	额外空间
O(n)	O(1)

189 · 轮转数组
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        if (n == 0) return;

        k %= n;
        if (k == 0) return;

        reverse(nums, 0, n - 1); // 翻转整体
        reverse(nums, 0, k - 1); // 恢复前 k 个元素的顺序
        reverse(nums, k, n - 1); // 恢复剩余元素的顺序
    }

    private void reverse(int[] nums, int left, int right) {
        while (left < right) {
            int temp = nums[left];
            nums[left] = nums[right];
            nums[right] = temp;
            left++;
            right--;
        }
    }
}

56 · 合并区间
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public int[][] merge(int[][] intervals) {
        if (intervals.length == 0) return new int[0][2];

        // 使用 Integer.compare，避免直接相减可能发生整数溢出
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        List<int[]> merged = new ArrayList<>();

        for (int[] current : intervals) {
            if (merged.isEmpty()
                    || merged.get(merged.size() - 1)[1] < current[0]) {
                // 创建新区间，避免与输入中的区间共用同一个 int[]
                merged.add(new int[]{current[0], current[1]});
            } else {
                int[] last = merged.get(merged.size() - 1);
                last[1] = Math.max(last[1], current[1]);
            }
        }

        return merged.toArray(new int[merged.size()][]);
    }
}

41 · 缺失的第一个正数
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;

        for (int i = 0; i < n; i++) {
            // 先检查范围，再访问目标下标；&& 具有短路特性
            while (nums[i] >= 1 && nums[i] <= n
                    && nums[nums[i] - 1] != nums[i]) {
                int target = nums[i] - 1;
                int temp = nums[i];
                nums[i] = nums[target];
                nums[target] = temp;
            }
        }

        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1;
        }
        return n + 1;
    }
}
