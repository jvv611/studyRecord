01 / 73 · 矩阵置零
首行首列作标记

要解决什么　原始位置为 0 时，将所在行和列全部置零。
💡 一句话记住

先记录，再统一修改；首行标列，首列标行。

① 怎么做
1. 先用两个布尔值保存原始首行、首列是否有 0。
2. 扫描内部区域，把行列标记写到首列、首行。
3. 根据标记清零内部区域。
4. 最后按布尔值处理首行、首列。
② 跟一遍例子
输入各行：[1,1,1] / [1,0,1] / [1,1,1]
输出各行：[1,0,1] / [0,0,0] / [1,0,1]
③ 最容易错的地方
- 不能发现 0 就立即清整行整列，新零会错误传播。
- 首行首列最后清，防止破坏标记。
- 行标记或列标记为 0，当前位置就置零。
时间	额外空间
O(mn)	O(1)

02 / 54 · 螺旋矩阵
四边界收缩

要解决什么　按顺时针螺旋顺序返回全部元素。
💡 一句话记住

每走完一条边，就把对应边界向内收一格。

① 怎么做
1. 上边向右，top++。
2. 右边向下，right--。
3. 下边向左，bottom--。
4. 左边向上，left++；继续下一圈。
② 跟一遍例子
[1,2,3] / [4,5,6] / [7,8,9]
上：1,2,3 → 右：6,9 → 下：8,7 → 左：4
内层：5
③ 最容易错的地方
- 外层条件：top<=bottom 且 left<=right。
- 走下边前检查 top<=bottom，走左边前检查 left<=right。
- 单行或单列最容易重复访问。
时间	额外空间
O(mn)	辅助 O(1)；输出 O(mn)

03 / 48 · 旋转图像
转置 + 逐行反转

要解决什么　将 n×n 方阵原地顺时针旋转 90°。
💡 一句话记住

坐标 (i,j) 需要变为 (j,n-1-i)。

① 怎么做
1. 先转置：(i,j) → (j,i)。
2. 再反转每一行：(j,i) → (j,n-1-i)。
② 跟一遍例子
原始：[1,2,3] / [4,5,6] / [7,8,9]
转置：[1,4,7] / [2,5,8] / [3,6,9]
反转：[7,4,1] / [8,5,2] / [9,6,3]
③ 最容易错的地方
- 转置只处理 j>i，避免同一对交换两次。
- 逐行反转是左右交换元素，不是上下交换整行。
- 先转置再反转；顺序反过来是逆时针旋转。
时间	额外空间
O(n²)	O(1)

04 / 240 · 搜索二维矩阵 II
右上角排除

要解决什么　每行、每列均升序，判断 target 是否存在。
💡 一句话记住

从右上角开始，大了左移，小了下移。

① 怎么做
1. 起点 row=0，col=n-1。
2. 当前值大于 target：排除当前列，col--。
3. 当前值小于 target：排除当前行，row++。
4. 相等则返回 true；越界则返回 false。
② 跟一遍例子
矩阵：[1,4,7] / [2,5,8] / [3,6,9]，找 5
7（大了，左移）→ 4（小了，下移）→ 5（找到）
③ 最容易错的地方
- 右上角是剩余当前行最大值、当前列最小值，因此可以整行整列排除。
- 行列有序不代表展开后全局有序，不能直接整体二分。
- 一般行列有序矩阵不一定能分解成两个数组的两两和。
时间	额外空间
O(m+n)	O(1)

73 · 矩阵置零
class Solution {
    public void setZeroes(int[][] matrix) {
        if (matrix.length == 0 || matrix[0].length == 0) return;
        int m = matrix.length, n = matrix[0].length;
        boolean firstRowZero = false, firstColZero = false;

        // 先保存原始首行、首列状态
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) firstRowZero = true;
        }
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) firstColZero = true;
        }

        // 内部区域产生标记，不在此时清零整行整列
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 根据标记修改内部区域
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 最后处理标记所在的首行、首列
        if (firstRowZero) {
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        }
        if (firstColZero) {
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
}

54 · 螺旋矩阵
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix.length == 0 || matrix[0].length == 0) return result;

        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) result.add(matrix[top][j]);
            top++;

            for (int i = top; i <= bottom; i++) result.add(matrix[i][right]);
            right--;

            if (top <= bottom) {
                for (int j = right; j >= left; j--) result.add(matrix[bottom][j]);
                bottom--;
            }

            if (left <= right) {
                for (int i = bottom; i >= top; i--) result.add(matrix[i][left]);
                left++;
            }
        }
        return result;
    }
}

class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // 只遍历主对角线上方，每对元素交换一次
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // 每一行左右反转
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }
}

240 · 搜索二维矩阵 II
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix.length == 0 || matrix[0].length == 0) return false;
        int row = 0, col = matrix[0].length - 1;

        while (row < matrix.length && col >= 0) {
            int value = matrix[row][col];
            if (value == target) return true;
            if (value > target) {
                col--;
            } else {
                row++;
            }
        }
        return false;
    }
}
