二、73：矩阵置零

1. 题意与样例

若原矩阵某位置为 0，则将其所在行、列全部置为 0。原地修改矩阵。

输入：             输出：
1 1 1             1 0 1
1 0 1             0 0 0
1 1 1             1 0 1

2. 为什么不能发现一个 0 就立即清零？

新产生的 0 不能作为原始零继续传播。 否则会将本来不该清零的行列也置零。

因此要分成两个阶段：记录原始零的位置所影响的行列 → 按标记统一清零。

3. 从标记数组到 O(1) 空间

基础做法用 boolean[m] 和 boolean[n]，记录哪些行、列有 0，时间 O(mn)，额外空间 O(m+n)。

优化时借用原矩阵首行首列：

标记位置

含义

matrix[i][0]

第 i 行是否需要清零

matrix[0][j]

第 j 列是否需要清零

firstRowZero

原始第一行是否存在 0

firstColZero

原始第一列是否存在 0

两个布尔变量必须在写入标记前计算；首行首列必须在内部区域处理完后再清零。

4. Java 代码

class Solution {
    public void setZeroes(int[][] matrix) {
        if (matrix.length == 0 || matrix[0].length == 0) return;
        int m = matrix.length, n = matrix[0].length;
        boolean firstRowZero = false, firstColZero = false;

        // 先保存原始首行、首列状态
        for (int j = 0; j < n; j++) {
            if (matrix[0][j] == 0) firstRowZero = true;
        }
        for (int i = 0; i < m; i++) {
            if (matrix[i][0] == 0) firstColZero = true;
        }

        // 内部区域产生标记，不在此时清零整行整列
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][j] == 0) {
                    matrix[i][0] = 0;
                    matrix[0][j] = 0;
                }
            }
        }

        // 根据标记修改内部区域
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                    matrix[i][j] = 0;
                }
            }
        }

        // 最后处理标记所在的首行、首列
        if (firstRowZero) {
            for (int j = 0; j < n; j++) matrix[0][j] = 0;
        }
        if (firstColZero) {
            for (int i = 0; i < m; i++) matrix[i][0] = 0;
        }
    }
}

5. 易错点与复杂度

首行标记列，首列标记行，不要记反。

内部区域的两个循环均从 1 开始，保护标记。

判断条件是行标记为 0 或 列标记为 0。

首行首列过早清零会破坏标记，导致错误扩散。

时间 O(mn)，额外空间 O(1)。

面试复述： 用首行首列记录行列是否需要清零，先用两个变量保存首行首列原始状态，再扫描内部区域做标记，按标记清零内部，最后处理首行首列。

三、54：螺旋矩阵

1. 题意与样例

按照顺时针螺旋顺序返回矩阵中的全部元素。

输入：
1 2 3
4 5 6
7 8 9
输出：[1,2,3,6,9,8,7,4,5]

2. 核心思路：维护未访问区域

top、bottom、left、right 表示还没有被访问的矩形边界，均为闭边界。

遍历方向

固定坐标

变化坐标

完成后

上边：从左到右

行 top

列 left → right

top++

右边：从上到下

列 right

行 top → bottom

下边：从右到左

行 bottom

列 right → left

左边：从下到上

列 left

行 bottom → top

收缩后再走下一边，避免重复处理四个角。只剩一行或一列时，尤其要检查边界是否相交。

3. Java 代码

import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> result = new ArrayList<>();
        if (matrix.length == 0 || matrix[0].length == 0) return result;

        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            for (int j = left; j <= right; j++) result.add(matrix[top][j]);
            top++;

            for (int i = top; i <= bottom; i++) result.add(matrix[i][right]);
            right--;

            if (top <= bottom) {
                for (int j = right; j >= left; j--) result.add(matrix[bottom][j]);
                bottom--;
            }

            if (left <= right) {
                for (int i = bottom; i >= top; i--) result.add(matrix[i][left]);
                left++;
            }
        }
        return result;
    }
}

5. 易错点与复杂度

外层条件为 top<=bottom && left<=right。

遍历下边前检查 top<=bottom，遍历左边前检查 left<=right。

不要求方阵，m 和 n 可以不同。

时间 O(mn)：每个元素输出一次。

辅助空间 O(1)，输出空间 O(mn)；如果把结果列表计入总空间，不能写总空间 O(1)。

面试复述： 用四条边界圈定未访问区域，依次访问上、右、下、左，每处理完一边就收缩对应边界。边界相交时停止，防止单行或单列被重复访问。

四、48：旋转图像

1. 题意与样例

把 n×n 方阵原地顺时针旋转 90°，不能额外创建矩阵。

输入：             输出：
1 2 3             7 4 1
4 5 6             8 5 2
7 8 9             9 6 3

2. 坐标推导

目标坐标变换：(i,j) → (j,n-1-i)。

分成两个原地步骤：

主对角线转置：(i,j) → (j,i)。

每一行左右反转：(j,i) → (j,n-1-i)。

阶段

矩阵各行

原矩阵

[1,2,3] / [4,5,6] / [7,8,9]

转置后

[1,4,7] / [2,5,8] / [3,6,9]

逐行反转后

[7,4,1] / [8,5,2] / [9,6,3]

“逐行左右反转”是交换每行左右两端的元素，不是交换整行的上下顺序。

3. Java 代码

class Solution {
    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // 只遍历主对角线上方，每对元素交换一次
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                int temp = matrix[i][j];
                matrix[i][j] = matrix[j][i];
                matrix[j][i] = temp;
            }
        }

        // 每一行左右反转
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }
}

4. 易错点与复杂度

转置内层从 j=i+1 开始。若把整个矩阵都交换一遍，同一对元素会交换两次，恢复原样。

操作顺序不能随意互换；先逐行反转再转置会变成逆时针旋转。

本题限定方阵，上述代码不能直接用于一般长方形矩阵的原地旋转。

时间 O(n²)，额外空间 O(1)。两步都是 O(n²)，无需将操作次数机械写成精确的 2n² 次。

面试复述： 顺时针旋转的坐标变换为 (i,j) 到 (j,n-1-i)。先转置交换行列坐标，再反转每行，即可实现该变换。转置时只处理主对角线一侧，避免重复交换。

五、240：搜索二维矩阵 II

1. 题意与样例

每一行从左到右升序，每一列从上到下升序，判断 target 是否存在。

matrix = [
  [1, 4, 7,11,15],
  [2, 5, 8,12,19],
  [3, 6, 9,16,22],
  [10,13,14,17,24],
  [18,21,23,26,30]
]
target = 5 → true

2. 核心思路：从右上角逐步排除

起点 (0,n-1)，此时当前位置是剩余当前行的最大值、剩余当前列的最小值。

比较

推理

移动

当前值 > target

当前列下方的值更大，不可能找到 target

col--，排除当前列

当前值 < target

当前行左侧的值更小，不可能找到 target

row++，排除当前行

当前值 = target

找到答案

返回 true

每次排除一整行或一整列，这是 O(m+n) 的依据。

为什么不从左上角开始？左上角的右边和下边都更大，当前值偏小时无法通过一次比较确定该排除哪一行或哪一列。右上角或左下角则有两个相反的变化方向。

3. Java 代码

class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        if (matrix.length == 0 || matrix[0].length == 0) return false;
        int row = 0, col = matrix[0].length - 1;

        while (row < matrix.length && col >= 0) {
            int value = matrix[row][col];
            if (value == target) return true;
            if (value > target) {
                col--;
            } else {
                row++;
            }
        }
        return false;
    }
}

5. 原文中需要修正的概念

“行列有序矩阵就是两个有序数组两两相加构成的矩阵”并不成立。 两个有序数组的两两和会产生行列有序矩阵，但一般的行列有序矩阵不一定能这样分解。

例如 [[1,2],[3,5]] 行列有序，但若能表示为 a[i]+b[j]，必须满足两条对角线之和相等；这里 1+5 != 2+3，所以无法分解。

可以用“两数组求和的双指针”作类比，但正确性依据是矩阵本身的行列单调性。

6. 易错点与复杂度

大了向左，小了向下，方向不要写反。

不要求每一行首元素大于上一行末元素；不能直接把矩阵展开成全局有序数组做二分。

时间 O(m+n)：行下标只增，列下标只减，访问位置最多 m+n−1 个（非空矩阵）。

额外空间 O(1)，找不到时越界退出并返回 false。

面试复述： 从右上角开始比较，当前值太大就排除这一列，太小就排除这一行。每步都会减少一行或一列候选范围，因此时间 O(m+n)，空间 O(1)。
