# 一、Java ACM 输入输出复习

这次三道题都属于典型 ACM 输入模式，Java 中主要需要掌握：

```text
输入：
BufferedReader
StringTokenizer

输出：
StringBuilder
```

## 1. Scanner 和 BufferedReader

`Scanner` 写法最简单：

```java
Scanner sc = new Scanner(System.in);

int n = sc.nextInt();
long x = sc.nextLong();
```

但是数据量变大以后，通常更推荐：

```java
BufferedReader br =
        new BufferedReader(new InputStreamReader(System.in));
```

再配合：

```java
StringTokenizer st =
        new StringTokenizer(br.readLine());
```

读取：

```java
int n = Integer.parseInt(st.nextToken());
```

可以简单记：

| 工具 | 作用 |
|---|---|
| `Scanner` | 简单，但速度较慢 |
| `BufferedReader` | 快速按行读取 |
| `StringTokenizer` | 拆分一行中的多个数据 |
| `StringBuilder` | 拼接大量输出 |

---

## 2. 推荐的 FastScanner 模板

算法题中可以自己封装：

```java
static class FastScanner {
    BufferedReader br =
            new BufferedReader(new InputStreamReader(System.in));

    StringTokenizer st;

    String next() throws IOException {
        while (st == null || !st.hasMoreTokens()) {
            st = new StringTokenizer(br.readLine());
        }
        return st.nextToken();
    }

    int nextInt() throws IOException {
        return Integer.parseInt(next());
    }

    long nextLong() throws IOException {
        return Long.parseLong(next());
    }
}
```

后面直接：

```java
FastScanner fs = new FastScanner();

int n = fs.nextInt();
int m = fs.nextInt();
```

这样不需要考虑数据究竟是不是在同一行。

---

## 3. StringBuilder 批量输出

例如第一题有很多查询：

```java
StringBuilder sb = new StringBuilder();

for (int i = 0; i < q; i++) {
    if (i > 0) {
        sb.append(' ');
    }

    sb.append(answer);
}

System.out.println(sb);
```

第三题每次修改都需要输出：

```java
StringBuilder sb = new StringBuilder();

for (...) {
    sb.append(answer).append('\n');
}

System.out.print(sb);
```

> [!TIP]
> 数据量较大时，通常不要在循环中频繁调用 `System.out.println()`，可以先使用 `StringBuilder` 拼好后统一输出。

# 三、第一题：并查集思想

## 1. 问题本质

题目中：

> 能够通过链路互相到达的芯片属于同一个时标域。

实际上就是：

```text
无向图中的连通块
```

例如：

```text
0 —— 2 —— 1

3 —— 4
```

可以分成：

```text
连通块1：0、1、2
连通块2：3、4
```

每一个连通块需要找：

```text
权重最大的芯片
```

如果权重相同：

```text
编号更小的芯片
```

---

# 四、并查集主要解决什么

并查集主要支持两个操作：

```text
find(x)
→ 找到 x 属于哪个集合

union(a, b)
→ 把 a 和 b 所在集合合并
```

核心数据：

```java
int[] parent;
```

初始状态：

```text
parent[0] = 0
parent[1] = 1
parent[2] = 2
...
```

表示：

```text
每个芯片一开始都自己组成一个集合
```

---

# 五、find：找集合代表元

最简单：

```java
int find(int x) {
    if (parent[x] == x) {
        return x;
    }

    return find(parent[x]);
}
```

但这样可能形成：

```text
1 → 2 → 3 → 4 → 5
```

每次查找都走很长。

因此加入：

```text
路径压缩
```

写成：

```java
int find(int x) {
    if (parent[x] != x) {
        parent[x] = find(parent[x]);
    }

    return parent[x];
}
```

第一次：

```text
1 → 2 → 3 → 4
```

查完以后直接：

```text
1 ─┐
2 ─┼→ 4
3 ─┘
```

以后查询就非常快。

> [!IMPORTANT]
> `find()` 的核心作用：
>
> **找到一个节点所在连通块的代表节点。**

---

# 六、union：合并两个集合

一条链路：

```text
u —— v
```

说明：

```text
u 和 v 属于同一个连通块
```

所以：

```java
int rootA = find(u);
int rootB = find(v);

if (rootA != rootB) {
    parent[rootB] = rootA;
}
```

如果：

```text
rootA == rootB
```

说明本来就已经连通。

例如：

```text
重复边
自环
```

都不会产生新的影响。

---

# 七、按秩合并

为了避免树变得太高，可以维护：

```java
int[] rank;
```

合并时：

```java
if (rank[rootA] < rank[rootB]) {
    parent[rootA] = rootB;
} else {
    parent[rootB] = rootA;

    if (rank[rootA] == rank[rootB]) {
        rank[rootA]++;
    }
}
```

即：

> **矮树挂到高树下面。**

配合：

```text
路径压缩
+
按秩合并
```

`find()` 和 `union()` 基本可以看成接近 `O(1)`。

---

# 八、链路处理完以后怎么找时标源

并查集只告诉我们：

```text
谁和谁在一个集合
```

还没有告诉我们：

```text
这个集合中权重最大的节点是谁
```

所以再扫描所有芯片：

```java
for (int i = 0; i < n; i++) {
    int root = find(i);
}
```

然后：

```java
int best = source[root];
```

判断：

```text
当前还没有时标源
或者
当前芯片权重更大
或者
权重相同但编号更小
```

写成：

```java
if (best == -1
        || weight[i] > weight[best]
        || (weight[i] == weight[best] && i < best)) {

    source[root] = i;
}
```

这是典型的：

```text
第一优先级：权重最大
第二优先级：编号最小
```

---

# 九、查询为什么很简单

查询某个芯片：

```java
int x = fs.nextInt();
```

先找到：

```java
int root = find(x);
```

然后：

```java
source[root]
```

就是：

```text
这个芯片所在时标域的时标源
```

整个第一题流程：

```text
每个芯片初始化独立
        ↓
处理所有链路
        ↓
union 合并连通块
        ↓
遍历所有芯片
        ↓
给每个连通块选时标源
        ↓
查询芯片 → find → source
```

# 十、第二题：数字分列最小差

第二题本质上有两层选择：

```text
第一层：
每个数字放左边还是右边

第二层：
同一边的数字按照什么顺序排列
```

所以：

```text
子集枚举
+
全排列
```

---

# 十一、为什么用二进制枚举

假设数字：

```text
7 2 5
```

每个数字有两个选择：

```text
左边
右边
```

因此三位二进制就能表示：

```text
001
010
011
100
101
110
```

其中：

```text
000
```

表示左边为空，

```text
111
```

表示右边为空。

题目要求：

```text
两边都至少一个数字
```

所以这两个方案必须跳过。

通用写法：

```java
int full = (1 << n) - 1;

for (int mask = 1; mask < full; mask++) {
}
```

---

# 十二、为什么左右对调只算一次

例如：

```text
mask = 001
```

代表：

```text
左：[7]
右：[2,5]
```

对应：

```text
mask = 110
```

则是：

```text
左：[2,5]
右：[7]
```

其实只是左右交换。

最后计算：

```text
large
small
diff
```

结果完全相同。

所以可以：

```java
int other = full ^ mask;

if (mask > other) {
    continue;
}
```

只处理其中一边。

---

# 十三、为什么还要去重划分

如果数字存在重复：

```text
1 1 2
```

虽然：

```text
两个 1 的下标不同
```

但交换两个 `1` 所得到的划分实际上完全一样。

因此可以把：

```text
左边数字排序
右边数字排序
```

然后生成一个唯一的 `key`：

```java
String key = left + "|" + right;
```

存入：

```java
HashSet<String> visited;
```

如果已经出现过：

```java
continue;
```

# 十四、每一边为什么还需要全排列

例如：

```text
左边：[1,2,3]
```

可以形成：

```text
123
132
213
231
312
321
```

因此不能只：

```text
排序以后拼一次
```

而是需要枚举所有排列。

这和上一道“双十一优惠券”中：

```text
优惠券选出来以后
还要枚举使用顺序
```

本质上是同一种思想：

> **集合确定之后，还要枚举顺序。**

---

# 十五、重复数字怎么避免重复排列

例如：

```text
1 1 2
```

如果普通全排列：

```text
第一个1
第二个1
```

虽然下标不同，但生成结果一样。

解决方式：

```text
先排序
+
同一递归层跳过重复数字
```

典型写法：

```java
if (i > 0
        && digits[i] == digits[i - 1]
        && !used[i - 1]) {
    continue;
}
```

最终只生成：

```text
112
121
211
```

而不会重复。

# 十六、怎么维护最小差

每得到：

```text
leftValue
rightValue
```

先统一：

```java
long large = Math.max(leftValue, rightValue);
long small = Math.min(leftValue, rightValue);
```

然后：

```java
long diff = large - small;
```

如果：

```text
diff < best
```

说明找到更优答案：

```java
best = diff;
pairs.clear();
pairs.add(...)
```

如果：

```text
diff == best
```

说明又找到一个最优整数对：

```java
pairs.add(...)
```

因为不同拆法可能形成同样的：

```text
large small
```

所以这里适合使用：

```java
Set
```

去重。

# 十七、第二题完整逻辑

```text
数字数组
   ↓
枚举左右两边的划分
   ↓
跳过空集合
   ↓
左右交换的情况只计算一次
   ↓
重复数字造成的同一划分去重
   ↓
左边生成所有不重复排列
   ↓
右边生成所有不重复排列
   ↓
两边所有整数两两组合
   ↓
计算 diff
   ↓
维护最小 diff 和所有答案
```

> [!WARNING]
> 这道题不是 DP。
>
> 它利用的是题目规模较小，因此可以通过 **暴力枚举所有可能情况** 找到最优解。

# 十八、第三题：为什么普通数组会超时

第三题开始：

```text
每个位置颜色都不同
```

然后不断执行：

```text
把 [L,R] 全部改成颜色 W
```

每改一次以后要问：

```text
当前最长连续同色段是多少？
```

最直接的方法：

```text
修改 [L,R]
再扫描整个数组
```

一次：

```text
O(n)
```

如果有 `q` 次：

```text
O(n × q)
```

数据量大时不可行。

所以使用：

```text
线段树 + 懒标记
```

---

# 十九、线段树为什么适合

线段树把：

```text
[1,n]
```

不断二分：

```text
          [1,n]
         /     \
    [1,m]      [m+1,n]
```

每个节点维护自己负责区间的信息。

因此：

```text
修改一个区间
```

不需要真的访问这个区间里的每一个位置。

---

# 二十、普通线段树只存最大值还不够

如果只是：

```java
max[p]
```

记录：

```text
这个区间最长同色段
```

无法正确合并左右子节点。

例如：

```text
左区间：
1 2 2

右区间：
2 2 3
```

左边最长：

```text
2
```

右边最长：

```text
2
```

但整体：

```text
2 2 | 2 2
```

中间连接以后长度：

```text
4
```

所以节点必须保存更多信息。

---

# 二十一、一个线段树节点需要维护什么

每个节点维护：

```text
lc  ：区间最左边的颜色
rc  ：区间最右边的颜色

pre：从左端开始的最长同色段
suf ：从右端开始的最长同色段

mx  ：整个区间最长同色段

lazy：整个区间是否被统一染成某种颜色
```

例如：

```text
2 2 2 3 4
```

那么：

```text
lc = 2
rc = 4
pre = 3
suf = 1
mx = 3
```

---

# 二十二、初始建树

一开始：

```text
第 i 个位置颜色 = i
```

因此每个叶子节点：

```text
lc = i
rc = i
pre = 1
suf = 1
mx = 1
```

然后不断：

```text
pushUp
```

合并父节点。

---

# 二十三、最核心：pushUp 怎么合并

设：

```text
左子树 = left
右子树 = right
```

父节点左右端颜色：

```java
leftColor[p] = leftColor[left];
rightColor[p] = rightColor[right];
```

初始最大值：

```java
max[p] = Math.max(max[left], max[right]);
```

如果：

```text
左子树最右颜色
==
右子树最左颜色
```

说明中间可以连起来。

于是：

```java
max[p] = Math.max(
        max[p],
        suffix[left] + prefix[right]
);
```

例如：

```text
左边：
1 2 2

右边：
2 2 3
```

那么：

```text
suffix[left] = 2
prefix[right] = 2
```

跨中点连续段：

```text
2 + 2 = 4
```

---

# 二十四、prefix 为什么也可能跨过去

假设：

```text
左区间整个都是颜色2
```

并且：

```text
右区间开头也是颜色2
```

那么父区间：

```text
从最左端开始的连续颜色2
```

实际上可以进入右子树。

所以：

```java
if (prefix[left] == leftLength) {
    prefix[p] += prefix[right];
}
```

同理，如果右区间整个颜色一致：

```java
if (suffix[right] == rightLength) {
    suffix[p] += suffix[left];
}
```

---

# 二十五、整段染色为什么可以直接修改节点

如果当前线段树节点负责：

```text
[l,r]
```

而修改区间完全包含它：

```text
ql <= l && r <= qr
```

那么：

```text
这一整段全部变成颜色 W
```

不需要继续递归到每一个叶子。

直接：

```java
leftColor[p] = W;
rightColor[p] = W;

prefix[p] = len;
suffix[p] = len;
max[p] = len;
lazy[p] = W;
```

因为现在整个区间：

```text
W W W W W W
```

最长同色段就是整个区间长度。

---

# 二十六、什么是懒标记

假设我们染：

```text
[1,100000]
```

如果真的更新十万个叶子：

```text
O(n)
```

就失去了线段树意义。

所以只在当前节点记录：

```text
lazy[p] = W
```

意思是：

> 这个节点下面整片区域实际上都已经是 W，只是我暂时没有继续往下更新。

以后真正需要访问子节点时：

```text
pushDown()
```

再把这个颜色传给左右子树。

这就是：

```text
懒标记 / Lazy Propagation
```

---

# 二十七、pushDown 怎么做

假设：

```java
lazy[p] = 8;
```

表示父节点全部是颜色8。

访问子节点前：

```java
apply(leftChild, leftLength, 8);
apply(rightChild, rightLength, 8);
```

然后：

```java
lazy[p] = -1;
```

表示父节点的标记已经传下去了。

> [!IMPORTANT]
> Lazy Tag 的核心思想：
>
> **能不往下更新，就先不更新；真正需要访问下面节点时才把修改传下去。**

---

# 二十八、区间修改 update

更新：

```text
[ql, qr] → W
```

如果当前节点：

```text
[l,r]
```

完全被覆盖：

```java
if (ql <= l && r <= qr)
```

直接：

```java
apply(...)
```

否则：

```text
pushDown
↓
看修改区间落在哪个子节点
↓
递归修改
↓
pushUp重新计算父节点
```

核心：

```java
if (ql <= mid) {
    update(left);
}

if (qr > mid) {
    update(right);
}

pushUp(p);
```

---

# 二十九、为什么每次答案直接是 `max[1]`

线段树：

```text
节点 1
```

就是：

```text
整条带子 [1,n]
```

而：

```java
max[p]
```

表示：

```text
p负责区间中的最长同色段
```

所以：

```java
max[1]
```

自然就是：

```text
整个数组当前最长连续同色段
```

每次更新以后直接：

```java
sb.append(max[1]).append('\n');
```

即可。

| 故障域时标同步 | 连通块 | 谁和谁属于同一集合 |

| 染后最长同色段 | 动态区间维护 | 修改后快速重新计算全局答案 |

可以形成三个条件反射：

```text
连通、合并、属于哪个集合
→ 并查集
```

```text
数量很小、每个元素选/不选
→ 二进制子集枚举
```

```text
区间频繁修改 + 区间/全局查询
→ 线段树 + 懒标记
```

## 第一题：并查集

```text
O((n + m + q) α(n))

O(n)
```

`α(n)` 增长极慢，实际可以近似理解成常数。

因此属于：

```text
指数 / 阶乘级暴力枚举
```

能使用这种方法的原因是：

```text
O(n + q log n)
```

空间：

```text
O(n)
```

通常线段树数组开：

即可。

# 三十三、题目与 Java 参考答案

## 第一题：故障域时标同步

### 核心

```text
链路 → union
查询 → find
每个连通块 → 找最大权重，权重相同取编号最小
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {

    static class FastScanner {
        BufferedReader br =
                new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st;

        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }

        long nextLong() throws IOException {
            return Long.parseLong(next());
        }
    }

    static int[] parent;
    static int[] rank;

    static int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }

        return parent[x];
    }

    static void union(int a, int b) {
        int rootA = find(a);
        int rootB = find(b);

        if (rootA == rootB) {
            return;
        }

        if (rank[rootA] < rank[rootB]) {
            parent[rootA] = rootB;
        } else if (rank[rootA] > rank[rootB]) {
            parent[rootB] = rootA;
        } else {
            parent[rootB] = rootA;
            rank[rootA]++;
        }
    }

    public static void main(String[] args) throws Exception {

        FastScanner fs = new FastScanner();

        int n = fs.nextInt();
        int m = fs.nextInt();

        long[] weight = new long[n];

        for (int i = 0; i < n; i++) {
            weight[i] = fs.nextLong();
        }

        parent = new int[n];
        rank = new int[n];

        for (int i = 0; i < n; i++) {
            parent[i] = i;
        }

        for (int i = 0; i < m; i++) {
            int u = fs.nextInt();
            int v = fs.nextInt();

            union(u, v);
        }

        int[] source = new int[n];
        Arrays.fill(source, -1);

        for (int i = 0; i < n; i++) {

            int root = find(i);
            int best = source[root];

            if (best == -1
                    || weight[i] > weight[best]
                    || (weight[i] == weight[best]
                    && i < best)) {

                source[root] = i;
            }
        }

        int q = fs.nextInt();

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < q; i++) {

            int chip = fs.nextInt();

            if (i > 0) {
                sb.append(' ');
            }

            sb.append(source[find(chip)]);
        }

        System.out.println(sb);
    }
}
```

# 第二题：数字分列最小差

### 核心

```text
mask
→ 枚举左右数字集合

回溯
→ 枚举每一边所有不重复排列

两边两两组合
→ 找最小差

Set
→ 去掉重复结果
```

### Java

```java
import java.io.*;
import java.util.*;

public class Main {

    static class FastScanner {
        BufferedReader br =
                new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st;

        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }

    static class Pair implements Comparable<Pair> {
        long large;
        long small;

        Pair(long large, long small) {
            this.large = large;
            this.small = small;
        }

        @Override
        public int compareTo(Pair other) {

            if (large != other.large) {
                return Long.compare(large, other.large);
            }

            return Long.compare(small, other.small);
        }
    }

    static void permutation(
            int[] nums,
            boolean[] used,
            int depth,
            long value,
            List<Long> result) {

        if (depth == nums.length) {
            result.add(value);
            return;
        }

        for (int i = 0; i < nums.length; i++) {

            if (used[i]) {
                continue;
            }

            // 同一层跳过重复数字
            if (i > 0
                    && nums[i] == nums[i - 1]
                    && !used[i - 1]) {
                continue;
            }

            used[i] = true;

            permutation(
                    nums,
                    used,
                    depth + 1,
                    value * 10 + nums[i],
                    result
            );

            used[i] = false;
        }
    }

    static List<Long> formNumbers(List<Integer> list) {

        int[] nums = new int[list.size()];

        for (int i = 0; i < list.size(); i++) {
            nums[i] = list.get(i);
        }

        Arrays.sort(nums);

        List<Long> result = new ArrayList<>();

        permutation(
                nums,
                new boolean[nums.length],
                0,
                0,
                result
        );

        return result;
    }

    public static void main(String[] args) throws Exception {

        FastScanner fs = new FastScanner();

        int n = fs.nextInt();

        int[] digits = new int[n];

        for (int i = 0; i < n; i++) {
            digits[i] = fs.nextInt();
        }

        int full = (1 << n) - 1;

        long best = Long.MAX_VALUE;

        TreeSet<Pair> answer = new TreeSet<>();
        HashSet<String> visited = new HashSet<>();

        for (int mask = 1; mask < full; mask++) {

            int other = full ^ mask;

            // 左右交换属于同一个划分
            if (mask > other) {
                continue;
            }

            List<Integer> left = new ArrayList<>();
            List<Integer> right = new ArrayList<>();

            for (int i = 0; i < n; i++) {

                if ((mask & (1 << i)) != 0) {
                    left.add(digits[i]);
                } else {
                    right.add(digits[i]);
                }
            }

            Collections.sort(left);
            Collections.sort(right);

            String leftKey = left.toString();
            String rightKey = right.toString();

            String key;

            if (leftKey.compareTo(rightKey) <= 0) {
                key = leftKey + "|" + rightKey;
            } else {
                key = rightKey + "|" + leftKey;
            }

            if (!visited.add(key)) {
                continue;
            }

            List<Long> leftNumbers = formNumbers(left);
            List<Long> rightNumbers = formNumbers(right);

            for (long x : leftNumbers) {

                for (long y : rightNumbers) {

                    long large = Math.max(x, y);
                    long small = Math.min(x, y);

                    long diff = large - small;

                    if (diff < best) {

                        best = diff;
                        answer.clear();
                        answer.add(new Pair(large, small));

                    } else if (diff == best) {

                        answer.add(new Pair(large, small));
                    }
                }
            }
        }

        StringBuilder sb = new StringBuilder();

        sb.append(answer.size()).append('\n');

        for (Pair pair : answer) {

            sb.append(pair.large)
              .append(' ')
              .append(pair.small)
              .append(' ')
              .append(pair.large - pair.small)
              .append('\n');
        }

        System.out.print(sb);
    }
}
```

# 第三题：染后最长同色段

### 核心

每个线段树节点维护：

```text
leftColor
rightColor

prefix
suffix

max

lazy
```

每次区间染色：

```text
update
↓
pushDown
↓
递归修改
↓
pushUp
```

最后：

```java
max[1]
```

就是整个数组最长连续同色段。

### Java

```java
import java.io.*;
import java.util.*;

public class Main {

    static class FastScanner {
        BufferedReader br =
                new BufferedReader(new InputStreamReader(System.in));

        StringTokenizer st;

        String next() throws IOException {
            while (st == null || !st.hasMoreTokens()) {
                st = new StringTokenizer(br.readLine());
            }
            return st.nextToken();
        }

        int nextInt() throws IOException {
            return Integer.parseInt(next());
        }
    }

    static int[] leftColor;
    static int[] rightColor;

    static int[] prefix;
    static int[] suffix;
    static int[] max;

    static int[] lazy;

    static void apply(
            int p,
            int length,
            int color) {

        leftColor[p] = color;
        rightColor[p] = color;

        prefix[p] = length;
        suffix[p] = length;
        max[p] = length;

        lazy[p] = color;
    }

    static void pushUp(
            int p,
            int l,
            int r) {

        int mid = (l + r) >> 1;

        int left = p << 1;
        int right = left | 1;

        leftColor[p] = leftColor[left];
        rightColor[p] = rightColor[right];

        prefix[p] = prefix[left];
        suffix[p] = suffix[right];

        max[p] = Math.max(
                max[left],
                max[right]
        );

        if (rightColor[left]
                == leftColor[right]) {

            max[p] = Math.max(
                    max[p],
                    suffix[left] + prefix[right]
            );

            int leftLength = mid - l + 1;
            int rightLength = r - mid;

            if (prefix[left] == leftLength) {
                prefix[p] += prefix[right];
            }

            if (suffix[right] == rightLength) {
                suffix[p] += suffix[left];
            }
        }
    }

    static void build(
            int p,
            int l,
            int r) {

        lazy[p] = -1;

        if (l == r) {

            leftColor[p] = l;
            rightColor[p] = l;

            prefix[p] = 1;
            suffix[p] = 1;
            max[p] = 1;

            return;
        }

        int mid = (l + r) >> 1;

        build(p << 1, l, mid);
        build(p << 1 | 1, mid + 1, r);

        pushUp(p, l, r);
    }

    static void pushDown(
            int p,
            int l,
            int r) {

        if (lazy[p] == -1) {
            return;
        }

        int mid = (l + r) >> 1;

        int left = p << 1;
        int right = left | 1;

        apply(
                left,
                mid - l + 1,
                lazy[p]
        );

        apply(
                right,
                r - mid,
                lazy[p]
        );

        lazy[p] = -1;
    }

    static void update(
            int p,
            int l,
            int r,
            int ql,
            int qr,
            int color) {

        if (ql <= l && r <= qr) {

            apply(
                    p,
                    r - l + 1,
                    color
            );

            return;
        }

        pushDown(p, l, r);

        int mid = (l + r) >> 1;

        if (ql <= mid) {
            update(
                    p << 1,
                    l,
                    mid,
                    ql,
                    qr,
                    color
            );
        }

        if (qr > mid) {
            update(
                    p << 1 | 1,
                    mid + 1,
                    r,
                    ql,
                    qr,
                    color
            );
        }

        pushUp(p, l, r);
    }

    public static void main(String[] args) throws Exception {

        FastScanner fs = new FastScanner();

        int n = fs.nextInt();
        int q = fs.nextInt();

        int size = n * 4 + 5;

        leftColor = new int[size];
        rightColor = new int[size];

        prefix = new int[size];
        suffix = new int[size];
        max = new int[size];

        lazy = new int[size];

        build(1, 1, n);

        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < q; i++) {

            int l = fs.nextInt();
            int r = fs.nextInt();
            int color = fs.nextInt();

            update(
                    1,
                    1,
                    n,
                    l,
                    r,
                    color
            );

            sb.append(max[1]).append('\n');
        }

        System.out.print(sb);
    }
}
```
