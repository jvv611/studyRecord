# P5614 双十一最低实付｜枚举子集 + 全排列回溯 + 模拟

> [!IMPORTANT]
> **这道题的核心不是动态规划，而是“把所有可能方案枚举出来，再模拟结算并取最小值”。**
>
> 整体流程可以记成：
>
> **凑单货选哪些 → 优惠券用哪些 → 优惠券按什么顺序用 → 模拟结算 → 更新最低实付**

---

## 一、题目核心

有三类输入：

- `a` 件必买商品：全部都要买；
- `b` 件凑单商品：每件可以选，也可以不选；
- `c` 张优惠券：每张可以用，也可以不用，而且使用顺序可以调整。

优惠券分两种：

- `f = 0`：减钱券，满足门槛后 `price -= d`
- `f = 1`：打折券，满足门槛后 `price = price * d / 100`

每张券使用前，都必须重新判断当前价格是否达到门槛 `g`。

> [!WARNING]
> 券的使用顺序会改变后续价格，所以不能只枚举“用哪些券”，还必须枚举“这些券按什么顺序用”。

---

## 二、程序执行顺序

虽然代码中的函数写在 `main()` 前面，但 Java 真正从 `main()` 开始执行。

```text
main()
  ↓
读取必买商品、凑单商品、优惠券
  ↓
lowestPay()
  ↓
枚举凑单商品子集
  ↓
枚举优惠券子集
  ↓
arrange()
  ↓
枚举优惠券所有使用顺序
  ↓
settle()
  ↓
按顺序真正结算
  ↓
best 保存全局最低实付
```

可以把四个核心部分理解为：

| 函数 / 变量 | 作用 |
|---|---|
| `main()` | 读取输入 |
| `lowestPay()` | 枚举“凑单货选哪些”和“优惠券用哪些” |
| `arrange()` | 枚举选中优惠券的所有排列顺序 |
| `settle()` | 按某一种顺序真正套券 |
| `best` | 保存目前出现过的最低实付 |

# 三、输入部分

## 1. 第一行

```java
int mustCount = input.nextInt();
int extraCount = input.nextInt();
int couponCount = input.nextInt();
```

分别表示：

```text
mustCount   = 必买商品数量 a
extraCount  = 凑单商品数量 b
couponCount = 优惠券数量 c
```

## 2. 必买商品

```java
long[] mustPrices = new long[mustCount];

for (int i = 0; i < mustCount; i++) {
    mustPrices[i] = input.nextLong();
}
```

例如：

```text
80 40
```

得到：

```text
mustPrices = [80, 40]
```

## 3. 凑单商品

```java
long[] extraPrices = new long[extraCount];

for (int i = 0; i < extraCount; i++) {
    extraPrices[i] = input.nextLong();
}
```

当 `extraCount = 0` 时，循环一次都不会执行，所以不需要额外判断。

## 4. 优惠券为什么必须是二维数组

每张券有三个数据：

```text
f g d
```

所以必须使用：

```java
long[][] coupons = new long[couponCount][3];
```

读取：

```java
for (int i = 0; i < couponCount; i++) {
    coupons[i][0] = input.nextLong(); // 类型 f
    coupons[i][1] = input.nextLong(); // 门槛 g
    coupons[i][2] = input.nextLong(); // 减免金额 / 折扣比例 d
}
```

可以记成：

```text
coupons[i][0] → 类型
coupons[i][1] → 门槛
coupons[i][2] → 优惠值
```

> [!WARNING]
> 不能写成 `int[] ticket = new int[c]`，因为一张券不是一个整数，而是三个整数。

# 四、先计算必买商品总价

进入：

```java
static long lowestPay(
        long[] mustPrices,

        long[][] coupons)
```

```java
long mustSum = 0;

for (long price : mustPrices) {
```

例如：

```text
必买商品：80 40
```

那么：

```text
mustSum = 120
```

接着：

```java
long best = Long.MAX_VALUE / 4;
```

`best` 用来记录：

> **到目前为止找到的最低实付价格。**

刚开始还没有任何答案，所以先赋一个很大的数。

# 五、`extraPrices.length` 是什么

代码：

```java
int extraCount = extraPrices.length;
int couponCount = coupons.length;
```

这里没有额外算法，只是取数组长度：

```text
extraPrices.length → 凑单商品数量 b
coupons.length     → 优惠券数量 c
```

Java 数组取长度使用：

```java
array.length
```

注意不是：

```java
array.length()
```

# 六、`1 << extraCount` 是什么意思

```java
1 << extraCount
```

是左移运算。

数值上等于：

```text
2 ^ extraCount
```

例如：

```text
1 << 0 = 1
1 << 1 = 2
1 << 2 = 4
1 << 3 = 8
```

为什么这里需要 `2^b`？

因为每一件凑单商品都有两种状态：

```text
选
不选
```

如果有 `b` 件商品：

```text
总方案数 = 2^b
```

所以：

```java
for (int mask = 0; mask < (1 << extraCount); mask++)
```

就是：

> **遍历所有凑单商品的选择方法。**

---

# 七、`mask` 怎么表示凑单方案

假设有 3 件凑单商品：

```text
A B C
```

那么所有方案可以用 3 位二进制表示：

| mask | 二进制 | 含义 |
|---:|---:|---|
| 0 | `000` | 全部不选 |
| 1 | `001` | 选第 0 件 |
| 2 | `010` | 选第 1 件 |
| 3 | `011` | 选第 0、1 件 |
| 4 | `100` | 选第 2 件 |
| 5 | `101` | 选第 0、2 件 |
| 6 | `110` | 选第 1、2 件 |
| 7 | `111` | 全部选择 |

因此：

```java
for (int mask = 0; mask < (1 << extraCount); mask++)
```

会把全部凑单方案走一遍。

---

# 八、怎么判断第 `i` 件商品有没有被选择

代码：

```java
if ((mask & (1 << i)) != 0) {
    total += extraPrices[i];
}
```

可以拆成两部分。

### `1 << i`

生成一个只有第 `i` 位为 `1` 的二进制数。

例如：

```text
i = 0 → 001
i = 1 → 010
i = 2 → 100
```

### `mask & (1 << i)`

使用按位与判断 `mask` 的第 `i` 位是不是 `1`。

```text
结果 != 0 → 第 i 件被选择
结果 == 0 → 第 i 件没有选择
```

所以：

```java
if ((mask & (1 << i)) != 0) {
    total += extraPrices[i];
}
```

就是：

> **如果当前凑单方案选择了第 `i` 件商品，就把它的价格加入订单总价。**

---

# 九、为什么 `total` 不需要保存所有可能价格

核心代码：

```java
for (int mask = 0; mask < (1 << extraCount); mask++) {
    long total = mustSum;

    for (int i = 0; i < extraCount; i++) {
        if ((mask & (1 << i)) != 0) {
            total += extraPrices[i];
        }
    }

    // 立刻拿当前 total 去枚举优惠券
}
```

`total` 只保存：

> **当前这一种凑单方案的价格。**

并不需要把所有方案的价格全部存进数组。

原因是：

```text
当前 mask
   ↓
算出当前 total
   ↓
立刻枚举当前 total 下的所有用券方法
   ↓
更新 best
   ↓
当前 total 已经完成任务
   ↓
进入下一个 mask，重新计算新的 total
```

真正需要跨方案保存的是：

```java
best
```

这和遍历数组求最小值类似：

```java
int min = Integer.MAX_VALUE;

for (...) {
    int cur = 当前值;
    min = Math.min(min, cur);
}
```

没有必要把所有 `cur` 都保存起来。

> [!IMPORTANT]
> **`total` = 当前方案。**
>
> **`best` = 所有已经检查过的方案中的最低价格。**

# 十、没有优惠券时为什么也能正常处理

凑单商品和优惠券是两套独立枚举。

即使：

```text
couponCount = 0
```

仍然有：

```java
1 << 0 = 1
```

所以：

```java
for (int use = 0; use < (1 << couponCount); use++)
```

只会执行：

```text
use = 0
```

也就是：

```text
一张券都不用
```

此时 `picked.length = 0`，`settle()` 会直接返回当前商品价格。

而在所有凑单方案中：

```text
mask = 0
```

本来就代表：

```text
一件凑单货都不加
```

所以无券情况下，程序也能自然覆盖“不凑单”的方案，不需要专门写特殊逻辑。

# 十一、第二层：枚举用哪些优惠券

当某个凑单方案的 `total` 已经确定后：

```java
for (int use = 0; use < (1 << couponCount); use++)
```

开始枚举：

> **这一次到底使用哪些优惠券。**

它和凑单商品的 `mask` 完全是同一个思想。

如果有两张券：

```text
A B
```

那么：

| use | 二进制 | 使用方案 |
|---:|---:|---|
| 0 | `00` | 都不用 |
| 1 | `01` | 只用 A |
| 2 | `10` | 只用 B |
| 3 | `11` | A、B 都用 |

---

# 十二、为什么先计算 `pickedCount`

```java
int pickedCount = 0;

for (int i = 0; i < couponCount; i++) {
    if ((use & (1 << i)) != 0) {
        pickedCount++;
    }
}
```

这里先统计：

> 当前 `use` 方案一共选择了多少张券。

因为后面需要创建：

```java
long[][] picked = new long[pickedCount][3];
```

例如：

```text
总共 3 张券
use = 101
```

表示选了第 0 张和第 2 张。

所以：

```text
pickedCount = 2
```

然后：

```java
picked = new long[2][3];
```

---

# 十三、把选择出来的券放进 `picked`

```java
int pos = 0;

for (int i = 0; i < couponCount; i++) {
    if ((use & (1 << i)) != 0) {
        picked[pos][0] = coupons[i][0];
        picked[pos][1] = coupons[i][1];
        picked[pos][2] = coupons[i][2];
        pos++;
    }
}
```

例如全部优惠券：

```text
A B C
```

当前：

```text
use = 101
```

那么最后：

```text
picked = [A, C]
```

此时只是决定：

```text
用 A 和 C
```

还没有决定：

```text
A → C
```

还是：

```text
C → A
```

因此还需要调用：

```java
best = arrange(total, picked, 0, best);
```

# 十四、为什么优惠券还要全排列

例如：

```text
总价 = 150

A：满100减20
B：满130打8折
```

如果：

```text
A → B
```

则：

```text
150 - 20 = 130
130 × 80 / 100 = 104
```

如果：

```text
B → A
```

则：

```text
150 × 80 / 100 = 120
120 - 20 = 100
```

同样两张券：

```text
A、B
```

只是顺序不同：

```text
104
100
```

结果就不同。

所以必须枚举所有排列。

---

# 十五、`arrange()` 是干什么的

函数：

```java
static long arrange(
        long total,
        long[][] picked,
        int start,
        long best)
```

参数：

```text
total  → 当前商品总价
picked → 当前决定使用的优惠券
start  → 当前正在决定排列的第几个位置
best   → 当前最低实付
```

它的作用只有一句话：

> **把 `picked` 中的券排列成所有可能顺序。**

---

# 十六、为什么 `start == picked.length` 表示排列完成

假设：

```text
picked = [A, B, C]
picked.length = 3
```

`start` 表示：

```text
现在准备确定哪个位置
```

过程：

```text
start = 0 → 决定第 0 位是谁
start = 1 → 决定第 1 位是谁
start = 2 → 决定第 2 位是谁
start = 3 → 已经没有位置需要决定
```

所以：

```java
if (start == picked.length)
```

说明：

```text
0 ~ length-1 的位置已经全部排好
```

此时 `picked` 已经是一种完整使用顺序。

于是：

```java
long paid = settle(total, picked);
```

真正计算这种顺序最后需要付多少钱。

---

# 十七、`arrange()` 的核心循环

```java
for (int i = start; i < picked.length; i++) {
    long[] tmp = picked[start];
    picked[start] = picked[i];
    picked[i] = tmp;

    best = arrange(total, picked, start + 1, best);

    tmp = picked[start];
    picked[start] = picked[i];
    picked[i] = tmp;
}
```

这就是：

> **交换 → 递归 → 换回来**

也就是标准回溯。

---

## 1. `i` 为什么从 `start` 开始

```java
for (int i = start; i < picked.length; i++)
```

因为：

```text
start 前面的所有位置已经确定
```

当前这一层只负责决定：

```text
picked[start] 放哪张券
```

所以只需要从：

```text
start ~ picked.length - 1
```

里面选择一张。

---

## 2. 第一次交换

```java
long[] tmp = picked[start];
picked[start] = picked[i];
picked[i] = tmp;
```

作用：

> 把第 `i` 张券放到当前 `start` 位置。

假设：

```text
picked = [A, B, C]
start = 0
i = 1
```

交换：

```text
[A, B, C]
↓
[B, A, C]
```

表示：

```text
第 0 个位置决定放 B
```

---

## 3. 递归

```java
best = arrange(total, picked, start + 1, best);
```

当前这一位已经确定了。

于是继续：

```text
start + 1
```

决定下一个位置。

例如：

```text
[B, A, C]
```

第 0 位已经确定是 `B`。

接下来：

```text
start = 1
```

继续决定第二张到底是 `A` 还是 `C`。

---

## 4. 为什么还要换回来

递归结束以后：

```java
tmp = picked[start];
picked[start] = picked[i];
picked[i] = tmp;
```

这是：

> **恢复现场。**

例如：

```text
原来：
[A, B, C]

为了尝试 B 在第一位：
[B, A, C]
```

这一整支递归全部结束后，必须恢复：

```text
[A, B, C]
```

然后才能继续试：

```text
C 在第一位
```

如果不恢复，后面的排列会被前一次修改影响。

> [!TIP]
> 回溯算法常见结构：
>
> ```text
> 做选择
> ↓
> 递归
> ↓
> 撤销选择
> ```

---

# 十八、三张券时 `arrange()` 会得到什么

假设：

```text
picked = [A, B, C]
```

最终会枚举：

```text
ABC
ACB
BAC
BCA
CAB
CBA
```

也就是：

```text
3! = 6
```

种顺序。

每得到一种完整顺序，就调用一次：

```java
settle(total, picked)
```

# 十九、`settle()`：真正按顺序套券

```java
static long settle(long price, long[][] chosen)
```

参数：

```text
price  → 当前订单价格
chosen → 已经排列好的券使用顺序
```

然后：

```java
for (long[] coupon : chosen)
```

按照顺序一张一张处理。

---

## 1. 判断门槛

```java
long gate = coupon[1];
long cut = coupon[2];

if (price < gate) {
    continue;
}
```

例如：

```text
当前 price = 120
券门槛 gate = 150
```

那么：

```text
120 < 150
```

这张券不能使用。

所以：

```java
continue;
```

跳过这张券，继续检查后面的券。

注意不是：

```java
break;
```

因为后面的券可能门槛更低，仍然可以使用。

---

## 2. 减钱券

```java
if (coupon[0] == 0) {
    price -= cut;
}
```

例如：

```text
price = 150
cut = 40
```

得到：

```text
110
```

---

## 3. 打折券

```java
else {
    price = price * cut / 100;
}
```

例如：

```text
price = 110
cut = 80
```

得到：

```text
110 × 80 / 100 = 88
```

因为全部使用整数，所以自动舍弃小数部分。

---

## 4. 最后价格不能小于 0

```java
if (price < 0) {
    return 0;
}
```

如果减钱券使最终价格变成负数：

```text
-20
```

最终按题目要求：

```text
0
```

# 二十、用样例 1 走完整流程

输入：

```text
2 1 2
80 40
30
0 150 40
1 100 80
```

### 第一步：必买商品

```text
80 + 40 = 120
```

所以：

```text
mustSum = 120
```

### 第二步：枚举凑单

只有一件 30 元凑单商品，所以：

```text
mask = 0 → 不凑单 → total = 120
mask = 1 → 凑单   → total = 150
```

### 第三步：`total = 120`

可尝试：

```text
不用券 → 120
只用减钱券 → 门槛150，不可用 → 120
只用8折券 → 120 × 80% = 96
两张都选：
    减钱 → 8折：减钱券先失败，之后8折 → 96
    8折 → 减钱：120→96，减钱券仍失败 → 96
```

当前：

```text
best = 96
```

### 第四步：`total = 150`

两张券都选择。

顺序一：

```text
减40 → 8折

150 - 40 = 110
110 × 80 / 100 = 88
```

顺序二：

```text
8折 → 减40

150 × 80 / 100 = 120
120 < 150
减钱券不能用
最终120
```

所以：

```text
best = 88
```

最终输出：

```text
88
```

# 二十一、整道题真正的算法结构

现在把所有代码压缩成一张图：

```text
必买商品
  ↓
计算 mustSum
  ↓
┌────────────────────────────┐
│ mask：枚举所有凑单商品子集 │
└────────────────────────────┘
  ↓
得到当前 total
  ↓
┌──────────────────────────┐
│ use：枚举所有优惠券子集  │
└──────────────────────────┘
  ↓
得到当前 picked
  ↓
┌──────────────────────────┐
│ arrange：枚举券所有排列  │
└──────────────────────────┘
  ↓
得到一种券顺序
  ↓
┌──────────────────────────┐
│ settle：真正模拟结算     │
└──────────────────────────┘
  ↓
得到 paid
  ↓
best = min(best, paid)
```

一句话记忆：

> **子集枚举负责“选哪些”，全排列负责“什么顺序”，模拟负责“算多少钱”。**

# 二十二、这道题涉及的知识点

| 知识点 | 对应代码 |
|---|---|
| 二进制 / 位运算 | `1 << n` |
| 子集枚举 | `mask`、`use` |
| 判断某元素是否选择 | `mask & (1 << i)` |
| 回溯 | 交换 → 递归 → 换回来 |
| 全排列 | `arrange()` |
| 模拟 | `settle()` |
| 极值维护 | `best` |

# 二十三、我最容易卡住的几个问题

## 1. `1 << extraCount` 为什么是所有凑单方案数？

因为每件商品只有：

```text
选 / 不选
```

两个状态。

`b` 件就是：

```text
2^b
```

种组合，而：

```java
1 << b
```

正好等于：

```text
2^b
```

---

## 2. `mask & (1 << i)` 为什么能判断有没有选择第 `i` 件？

因为：

```java
1 << i
```

只留下第 `i` 位。

再和 `mask` 做按位与：

```text
第 i 位是1 → 结果非0
第 i 位是0 → 结果为0
```

---

## 3. 为什么 `total` 不保存所有价格？

因为当前 `total` 在被覆盖之前，已经：

```text
枚举完所有用券方式
→ 更新了 best
```

所以它完成任务后就可以丢掉。

真正需要保存全部方案最优结果的是：

```java
best
```

---

## 4. 为什么 `start == picked.length` 就表示排好了？

因为：

```text
start = 0 → 决定第0位
start = 1 → 决定第1位
...
start = length → 所有位置都决定完成
```

所以可以进入 `settle()`。

---

## 5. 为什么递归后要再交换回来？

因为需要恢复数组，让下一次循环从同样的原始状态开始尝试其他券。

这是回溯的：

```text
选择 → 递归 → 撤销选择
```

# 二十五、完整代码

```java
import java.util.Scanner;

public class Main {

    // 按确定好的顺序使用优惠券
    static long settle(long price, long[][] chosen) {

        for (long[] coupon : chosen) {

            long gate = coupon[1];
            long cut = coupon[2];

            // 当前价格达不到门槛，这张券跳过
            if (price < gate) {
                continue;
            }

            if (coupon[0] == 0) {
                // 减钱券
                price -= cut;
            } else {
                // 打折券
                price = price * cut / 100;
            }
        }

        // 最低实付为0
        if (price < 0) {
            return 0;
        }

        return price;
    }

    // 对当前选中的优惠券进行全排列
    static long arrange(
            long total,
            long[][] picked,
            int start,
            long best) {

        // 所有位置都已经确定
        if (start == picked.length) {

            long paid = settle(total, picked);

            return Math.min(best, paid);
        }

        // 决定 picked[start] 位置应该放哪张券
        for (int i = start; i < picked.length; i++) {

            // 交换：选择第 i 张券放到 start
            long[] tmp = picked[start];
            picked[start] = picked[i];
            picked[i] = tmp;

            // 当前位确定，递归决定下一位
            best = arrange(
                    total,
                    picked,
                    start + 1,
                    best
            );

            // 回溯：恢复原数组
            tmp = picked[start];
            picked[start] = picked[i];
            picked[i] = tmp;
        }

        return best;
    }

    static long lowestPay(
            long[] mustPrices,
            long[] extraPrices,
            long[][] coupons) {

        // 1. 计算必买商品总价
        long mustSum = 0;

        for (long price : mustPrices) {
            mustSum += price;
        }

        long best = Long.MAX_VALUE / 4;

        int extraCount = extraPrices.length;
        int couponCount = coupons.length;

        // 2. 枚举所有凑单商品子集
        for (int mask = 0;
             mask < (1 << extraCount);
             mask++) {

            long total = mustSum;

            // 当前 mask 选择了哪些凑单商品
            for (int i = 0; i < extraCount; i++) {

                if ((mask & (1 << i)) != 0) {
                    total += extraPrices[i];
                }
            }

            // 3. 枚举使用哪些优惠券
            for (int use = 0;
                 use < (1 << couponCount);
                 use++) {

                int pickedCount = 0;

                // 先统计当前选了多少张券
                for (int i = 0; i < couponCount; i++) {

                    if ((use & (1 << i)) != 0) {
                        pickedCount++;
                    }
                }

                // 保存选中的优惠券
                long[][] picked =
                        new long[pickedCount][3];

                int pos = 0;

                for (int i = 0; i < couponCount; i++) {

                    if ((use & (1 << i)) != 0) {

                        picked[pos][0] = coupons[i][0];
                        picked[pos][1] = coupons[i][1];
                        picked[pos][2] = coupons[i][2];

                        pos++;
                    }
                }

                // 4. 枚举这些券的所有使用顺序
                best = arrange(
                        total,
                        picked,
                        0,
                        best
                );
            }
        }

        return best;
    }

    public static void main(String[] args) {

        Scanner input = new Scanner(System.in);

        int mustCount = input.nextInt();
        int extraCount = input.nextInt();
        int couponCount = input.nextInt();

        // 必买商品
        long[] mustPrices =
                new long[mustCount];

        for (int i = 0; i < mustCount; i++) {
            mustPrices[i] = input.nextLong();
        }

        // 凑单商品
        long[] extraPrices =
                new long[extraCount];

        for (int i = 0; i < extraCount; i++) {
            extraPrices[i] = input.nextLong();
        }

        // 优惠券
        long[][] coupons =
                new long[couponCount][3];

        for (int i = 0; i < couponCount; i++) {

            coupons[i][0] = input.nextLong();
            coupons[i][1] = input.nextLong();
            coupons[i][2] = input.nextLong();
        }

        System.out.println(
                lowestPay(
                        mustPrices,
                        extraPrices,
                        coupons
                )
        );

        input.close();
    }
}
```
