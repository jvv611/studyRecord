# 模拟题学习总结

> [!IMPORTANT]
> **今天的核心：模拟题的难点通常不是算法复杂，而是能否把题目的输入、判断规则、排序规则和流程完整地翻译成代码。**

---

## 一、今天主要学习了什么

今天三道题分别练习了三类很典型的模拟能力：

| 题目类型 | 核心知识 | 主要 Java API |
|---|---|---|
| 字符串前缀统计 | 字符串判断、HashMap 计数、自定义排序 | `startsWith()`、`getOrDefault()`、`Comparator` |
| 相邻时间间隔 | 顺序扫描、维护前驱、极值更新、并列处理 | `Scanner`、`Math` 思维 |
| 决策树推理 | 类建模、数组存树、循环模拟树遍历 | `class`、对象数组、`while` |

这三道题共同的特点是：

> **题目已经把规则告诉你了，代码的任务就是严格执行这些规则。**

和动态规划相比：

```text
动态规划：
寻找状态之间的最优转移关系

模拟题：
按照题意一步一步执行规则
```

---

# 二、模拟题的一般做题思路

做模拟题时，可以固定按照下面几个步骤分析：

1. **输入是什么格式？**
2. **需要保存哪些信息？**
3. **每读到一个数据，要做什么判断？**
4. **是否需要统计、排序或更新极值？**
5. **有没有并列、空结果、边界情况？**
6. **最终按什么格式输出？**

> [!TIP]
> 模拟题代码不一定长，但最容易因为某一条题意漏掉而出错，所以要特别关注“排序规则”“并列规则”“空结果”和“输入结束条件”。

# 三、Scanner 的两种常见读取方式

今天前两题都涉及一种很重要的 ACM 输入形式：

## 1. 已知数据数量

例如：

```text
3 9 2
```

已经知道后面要读取多少数据，可以直接：

```java
int f = sc.nextInt();
int m = sc.nextInt();
int n = sc.nextInt();

for (int i = 0; i < m; i++) {
    // 固定读取 m 行
}
```

这种属于：

```text
已知 n
↓
for 循环读取
```

---

## 2. 不知道数据数量，读取到 EOF

例如：

```text
hello hello hell help he hello
```

或者：

```text
3 2
8 5
2 9
4 10
```

题目没有告诉你到底有多少组数据，这时候使用：

```java
while (sc.hasNext()) {
    String s = sc.next();
}
```

字符串：

```java
while (sc.hasNext()) {
    String s = sc.next();
}
```

整数：

```java
while (sc.hasNextInt()) {
    int x = sc.nextInt();
}
```

可以记成：

```text
hasNext()     → 后面还有没有 token
next()        → 读取字符串

hasNextInt()  → 后面还有没有整数
nextInt()     → 读取整数
```

> [!WARNING]
> `hasNext()` 返回的是 `boolean`，它只负责判断，不负责读取。
>
> 错误：
>
> ```java
> al.add(sc.hasNext());
> ```
>
> 正确：
>
> ```java
> while (sc.hasNext()) {
>     al.add(sc.next());
> }
> ```

# 四、字符串常用 API

第一题集中练习了几个很重要的字符串操作。

## 1. length()

字符串长度：

```java
String s = "hello";

System.out.println(s.length());
```

结果：

```text
5
```

注意：

```text
数组     → length
字符串   → length()
集合     → size()
```

这是 Java 中很容易混淆的一点。

---

## 2. charAt(index)

获得字符串某个位置的字符：

```java
String s = "hello";

char c = s.charAt(1);
```

得到：

```text
'e'
```

`charAt()` 必须传下标：

```java
s.charAt(i)
```

不能：

```java
s.charAt()
```

而且返回类型是：

```java
char
```

不是：

```java
String
String[]
```

---

## 3. startsWith()

判断一个字符串是否是另一个字符串的前缀。

```java
String target = "hello";

target.startsWith("hell"); // true
target.startsWith("he");   // true
target.startsWith("help"); // false
```

所以题目中：

```java
if (a.length() <= target.length()
        && target.startsWith(a)) {
    // 匹配成功
}
```

实际上已经完成了：

```text
长度判断
+
从第一个字符开始逐个比较
```

因此没有必要自己再写 `charAt()` 循环。

> [!TIP]
> 能直接使用 Java 标准 API 表达题意时，通常比自己手写循环更简洁，也更不容易出现边界错误。

# 五、HashMap 计数

第一题要求：

```text
统计每个不同字符串出现多少次
```

这就是非常典型的：

```text
HashMap<元素, 次数>
```

例如：

```java
Map<String, Integer> map = new HashMap<>();
```

普通写法：

```java
if (map.containsKey(a)) {
    map.put(a, map.get(a) + 1);
} else {
    map.put(a, 1);
}
```

可以简化成：

```java
map.put(a, map.getOrDefault(a, 0) + 1);
```

含义是：

```text
如果 a 已经存在
    取原来的次数

如果 a 不存在
    默认次数为 0

最后统一 +1
```

所以看到：

```text
统计次数
统计频率
统计出现数量
```

可以优先想到：

```java
HashMap
+
getOrDefault()
```

# 六、自定义排序 Comparator

第一题不能直接按默认字典序排序，因为题目要求：

```text
第一关键字：长度降序
第二关键字：字典序升序
```

因此需要自定义比较器：

```java
Collections.sort(keys, new Comparator<String>() {
    @Override
    public int compare(String x, String y) {

        if (x.length() != y.length()) {
            return Integer.compare(y.length(), x.length());
        }

        return x.compareTo(y);
    }
});
```

理解 Comparator 最重要的是：

```text
返回负数 → x 排在 y 前面
返回正数 → y 排在 x 前面
返回 0   → 两者相等
```

长度要求：

```text
大 → 小
```

因此：

```java
Integer.compare(y.length(), x.length());
```

字典序要求：

```text
小 → 大
```

因此：

```java
x.compareTo(y);
```

> [!IMPORTANT]
> 多条件排序通常按照：
>
> ```text
> 先比较第一关键字
> 第一关键字相同，再比较第二关键字
> ```

这种题以后会经常遇到。

# 七、相邻元素问题：保存前一个值

第二题要求计算：

```text
当前时间 - 前一个时间
```

这种题并不一定需要数组。

只需要保存：

```java
int prev = 0;
```

每读一个事件：

```java
int dur = activationTime - prev;
```

处理完：

```java
prev = activationTime;
```

整体就是：

```text
当前数据
   ↓
和 prev 计算
   ↓
更新结果
   ↓
prev = 当前数据
```

这是典型的：

**单次扫描 + 前驱变量**

优点是不用把全部数据存下来。

空间复杂度：

```text
O(1)
```

---

# 八、极值更新与并列处理

第二题不只是找：

```text
最小间隔
最大间隔
```

还有一个很重要的规则：

```text
如果时间相同，sensor_id 取较小值
```

因此不能只写：

```java
if (dur < minDur)
```

而应该写：

```java
if (dur < minDur
        || (dur == minDur && sensorId < minId)) {

    minDur = dur;
    minId = sensorId;
}
```

意思是：

```text
情况1：找到更小的持续时间
       → 更新

情况2：持续时间一样，但 id 更小
       → 也更新
```

最大值同理：

```java
if (dur > maxDur
        || (dur == maxDur && sensorId < maxId)) {

    maxDur = dur;
    maxId = sensorId;
}
```

> [!IMPORTANT]
> 看到“如果相同则……”这种描述，就说明判断条件一般不只是单纯的 `<` 或 `>`，还需要处理第二优先级。

这和第一题的多条件排序，本质上其实是同一种思想：

```text
先比较主要条件
主要条件相同
再比较次要条件
```

# 九、边读边处理，而不是所有数据都存下来

第一题必须保存候选字符串，因为后面需要：

```text
统计
排序
输出
```

第二题则没有必要。

因为我们只关心：

```text
前一个 activation_time
当前最小值
当前最大值
对应 id
```

所以直接：

```java
while (sc.hasNextInt()) {
    ...
}
```

边读取边处理即可。

这也是写算法时一个值得注意的习惯：

> **不要默认所有输入都要保存进数组。**

先考虑：

```text
后续是否还需要这些历史数据？
```

如果不需要，就可以使用变量直接维护状态。

# 十、决策树问题：先设计数据结构

第三题的数据明显比前两题复杂：

每一个节点都有：

```text
feature_index
threshold
left
right
label
```

如果全部拆成五个数组：

```java
int[] featureIndex;
double[] threshold;
int[] left;
int[] right;
int[] label;
```

虽然也能写，但不够直观。

更适合定义一个节点类：

```java
static class Node {
    int featureIndex;
    double threshold;
    int left;
    int right;
    int label;
}
```

然后：

```java
Node[] tree = new Node[m];
```

这样：

```java
tree[i]
```

就是完整的第 `i` 个节点。

> [!TIP]
> 当一组数据始终属于同一个对象时，可以考虑使用 `class` 把这些字段包装起来。

# 十一、决策树本质上也是模拟

第三题虽然名字叫：

```text
决策树
```

但并不需要学习机器学习算法。

题目已经把树训练好了，我们只需要模拟：

```text
从根节点开始
       ↓
读取当前节点
       ↓
判断是不是叶子
       ↓
不是叶子就比较特征和阈值
       ↓
进入左子树或右子树
       ↓
继续
```

核心代码：

```java
int current = 0;

while (true) {
    Node node = tree[current];

    if (node.featureIndex == -1) {
        System.out.println(node.label);
        break;
    }

    if (features[node.featureIndex] <= node.threshold) {
        current = node.left;
    } else {
        current = node.right;
    }
}
```

这其实就是：

**while 循环模拟树的路径。**

# 十二、为什么 current = 0？

题目规定：

```text
模型第 0 行就是根节点
```

所以：

```java
int current = 0;
```

代表：

```text
当前正在访问根节点
```

之后：

```java
current = node.left;
```

或者：

```java
current = node.right;
```

本质是在：

```text
改变当前节点下标
```

因为题目已经直接给出了左右子节点在数组中的行号，所以不需要真的创建：

```java
Node left;
Node right;
```

这种指针结构。

可以理解为：

```text
tree 数组 = 存储整棵树

left/right = 下一节点的数组下标
```

# 十三、如何判断叶子节点

题目规定：

```text
叶子节点没有分裂特征
feature_index = -1
```

所以：

```java
if (node.featureIndex == -1) {
    System.out.println(node.label);
```

这里一定要：

```java
break;
```

因为找到叶子后，这个样本的推理已经结束。

这也是模拟题常见模式：

```text
while (...)
    如果达到终止状态
        输出
        break
```

# 十七、题目与代码答案

## 题目一：字符串前缀匹配统计

### 题目核心

给定一个目标字符串和若干候选字符串：

- 候选必须是目标字符串的前缀；
- 统计不同候选出现次数；
- 先按长度降序；
- 长度相同按字典序升序；
- 没有结果输出 `null`。

### 核心知识

```text
startsWith()
HashMap
getOrDefault()
Comparator
```

### 代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        ArrayList<String> al = new ArrayList<>();

        while (sc.hasNext()) {
            al.add(sc.next());
        }
        sc.close();

        if (al.isEmpty()) {
            return;
        }

        String target = al.get(0);
        Map<String, Integer> count = new HashMap<>();

        for (int i = 1; i < al.size(); i++) {
            String s = al.get(i);

            if (s.length() <= target.length()
                    && target.startsWith(s)) {

                count.put(
                        s,
                        count.getOrDefault(s, 0) + 1
                );
            }
        }

        if (count.isEmpty()) {
            System.out.println("null");
            return;
        }

        List<String> keys =
                new ArrayList<>(count.keySet());

        Collections.sort(keys, new Comparator<String>() {
            @Override
            public int compare(String x, String y) {

                if (x.length() != y.length()) {
                    return Integer.compare(
                            y.length(),
                            x.length()
                    );
                }

                return x.compareTo(y);
            }
        });

        for (String key : keys) {
            System.out.println(
                    key + " " + count.get(key)
            );
        }
    }
}
```

## 题目二：传感器相邻激活间隔极值

### 题目核心

每条记录：

```text
sensor_id activation_time
```

持续时间：

```text
当前 activation_time - 前一个 activation_time
```

首条记录：

```text
activation_time - 0
```

求：

```text
最短时间对应 id
最长时间对应 id
```

如果时间相同：

```text
id 小的优先
```

### 核心知识

```text
单次扫描
prev
维护 min / max
并列规则
```

### 代码

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int prev = 0;

        int minDur = Integer.MAX_VALUE;
        int maxDur = Integer.MIN_VALUE;

        int minId = -1;
        int maxId = -1;

        boolean hasEvent = false;

        while (sc.hasNextInt()) {

            int sensorId = sc.nextInt();
            int activationTime = sc.nextInt();

            hasEvent = true;

            int dur = activationTime - prev;

            if (dur < minDur
                    || (dur == minDur && sensorId < minId)) {

                minDur = dur;
                minId = sensorId;
            }

            if (dur > maxDur
                    || (dur == maxDur && sensorId < maxId)) {

                maxDur = dur;
                maxId = sensorId;
            }

            prev = activationTime;
        }

        if (hasEvent) {
            System.out.println(minId + " " + maxId);
        }

        sc.close();
    }
}
```

> [!NOTE]
> 原代码里的 `hasEvent = true` 如果一开始就赋值为 `true`，那么这个变量实际上失去了判断“是否读取到数据”的意义。更严谨的写法是初始化为 `false`，真正读到事件后再设为 `true`。
>
> 不过本题约束规定事件数至少为 `1`，因此也可以直接省略这个变量。

## 题目三：决策树资源调配优先级推理

### 题目核心

每个节点包含：

```text
分裂特征
阈值
左子节点
右子节点
分类结果
```

每个样本从根节点 `0` 开始：

```text
feature <= threshold
        ↓
      左子树

feature > threshold
        ↓
      右子树
```

直到：

```text
feature_index == -1
```

说明到达叶子，输出 `label`。

### 核心知识

```text
class 建模
对象数组
树的顺序存储
while 模拟路径
```

### 代码

```java
import java.util.*;

public class Main {

    static class Node {
        int featureIndex;
        double threshold;
        int left;
        int right;
        int label;

        Node(
                int featureIndex,
                double threshold,
                int left,
                int right,
                int label
        ) {
            this.featureIndex = featureIndex;
            this.threshold = threshold;
            this.left = left;
            this.right = right;
            this.label = label;
        }
    }

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        int f = sc.nextInt();
        int m = sc.nextInt();
        int n = sc.nextInt();

        Node[] tree = new Node[m];

        for (int i = 0; i < m; i++) {

            int featureIndex = sc.nextInt();
            double threshold = sc.nextDouble();
            int left = sc.nextInt();
            int right = sc.nextInt();
            int label = sc.nextInt();

            tree[i] = new Node(
                    featureIndex,
                    threshold,
                    left,
                    right,
                    label
            );
        }

        for (int i = 0; i < n; i++) {

            double[] features = new double[f];

            for (int j = 0; j < f; j++) {
                features[j] = sc.nextDouble();
            }

            int current = 0;

            while (true) {

                Node node = tree[current];

                if (node.featureIndex == -1) {
                    System.out.println(node.label);
                    break;
                }

                if (features[node.featureIndex]
                        <= node.threshold) {

                    current = node.left;

                } else {

                    current = node.right;
                }
            }
        }

        sc.close();
    }
}
```

# 十八、复杂度总结

| 题目 | 时间复杂度 | 空间复杂度 |
|---|---:|---:|
| 前缀匹配统计 | `O(n log n)` | `O(n)` |
| 相邻时间极值 | `O(n)` | `O(1)` |
| 决策树推理 | `O(n × h)` | `O(m + f)` |

其中：

```text
n = 数据或样本数量
m = 决策树节点数量
h = 决策树高度
f = 特征数量
```

第一题主要的 `O(n log n)` 来自最终排序。
